# 安全基础学习框架

## 学习目标

网络安全知识应同时覆盖资产、身份、协议、主机、应用、数据和监控。分析问题时先明确资产边界、信任边界、攻击面和业务影响，再讨论技术细节。

## 常见概念

- **资产**：主机、服务、应用、账号、数据和云资源。
- **攻击面**：可被访问、输入、配置或信任关系影响的入口。
- **威胁建模**：识别攻击者能力、资产价值、入口、滥用路径和缓解措施。
- **漏洞**：可能导致机密性、完整性或可用性影响的缺陷或错误配置。
- **风险**：漏洞被利用的可能性与影响的综合判断。

## 通用分析顺序

1. 确认授权范围和测试时间窗口。
2. 识别资产、入口、身份和数据流。
3. 建立可重复的假设和最小验证步骤。
4. 记录请求、响应、日志、时间戳和影响证据。
5. 给出可验证的修复建议并进行复测。

## 安全边界

本知识库只用于授权环境、隔离实验室和 CTF。遇到真实目标时，不应尝试扩大范围、绕过访问控制、窃取凭据或隐藏活动。
