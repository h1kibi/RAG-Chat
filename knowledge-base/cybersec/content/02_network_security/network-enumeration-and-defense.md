# 网络资产分析与防御

## 授权资产清单

先建立范围内的主机、域名、端口、服务、版本、负责人和暴露面清单。被动信息和配置审查通常应先于主动探测；主动探测必须遵守速率、时间窗口和禁止事项。

## 服务分析

对服务分析时关注：是否必要、是否暴露到不可信网络、是否启用加密、认证是否强制、版本是否受支持、默认配置是否改变以及日志是否完整。

## 防御控制

- 使用网络分段和最小暴露原则。
- 对管理面使用 VPN、跳板和强身份认证。
- 对外服务启用 TLS、限流、WAF 或 API 网关等适当控制。
- 统一资产、漏洞、配置和日志管理。
- 将探测行为与告警规则、流量基线和变更记录关联。

## 报告要求

不要只给出端口列表；应说明资产归属、业务用途、风险、可利用前置条件、检测证据和优先级。
