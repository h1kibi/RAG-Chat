# CTF 题目分析与复盘方法

CTF 只在竞赛平台或本地靶场中进行。目标是学习分析方法，不把题目中的技巧直接套用到未授权系统。

## 通用流程

1. 阅读题目描述、附件和 flag 格式。
2. 识别题型：Web、Pwn、Reverse、Crypto、Forensics 或 Misc。
3. 建立假设，使用最小实验验证，并记录输入、输出和错误。
4. 分阶段保存证据和脚本，避免只保留最终答案。
5. 复盘根因、关键线索、失败尝试和可迁移知识。

## Web 题

先看请求流程、身份状态、输入位置、错误信息、源码或附件，再判断是认证、授权、输入处理、业务逻辑还是配置问题。优先在本地复制题目环境。

## 二进制与逆向题

区分静态分析、动态调试、内存布局、调用约定、输入校验和程序状态。任何调试和脚本都应针对题目提供的二进制或本地副本。

## 复盘模板

题目目标、环境、线索、假设、验证、关键漏洞/算法、最终路径、失败路径、修复或防御启示。
